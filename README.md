# 산업연관표 분석 웹앱 (2023)

2023년 산업연관표(연장표)를 브라우저에서 바로 탐색하고, 수요 증가가 경제 전체에 미치는 파급효과를 계산하는 웹앱입니다. 별도의 서버 없이 GitHub Pages에서 동작하며, 계산은 방문자의 브라우저 안에서 Pyodide(WebAssembly 기반 Python)로 수행됩니다.

- 웹앱 주소: https://y99605699-blip.github.io/dbdpwls/
- 과목: 산업조직론 과제물 1

## 1. 주요 기능

| 기능 | 설명 |
|---|---|
| 부문 분류 선택 | 기본부문, 소분류, 중분류, 대분류 투입산출표 중 하나를 골라 불러옴 |
| 원자료 탐색 | 엑셀의 모든 시트를 선택하고, 행(산업)을 검색해 고른 뒤 각 열과의 연결 값을 확인 |
| 열 검색 | 열 코드·이름으로 필터링 |
| 수요충격 시뮬레이션 | 여러 산업의 최종수요 증가액을 합산 입력해 생산·수입·부가가치 유발액 계산 |
| 연쇄효과 분석 | 산업별 영향력계수(후방연쇄), 감응도계수(전방연쇄), 유발계수 합, 산업 유형 분류 |
| 연쇄효과 심화 | 변동계수, 직접 부가가치율, 직접 수입의존도, 영향력·감응도 산점도 |
| 최종수요 구조 | 민간소비·정부소비·민간투자·정부투자·수출별 유발 구조, 공공수요 비중, 수요 유형 분류 |
| 공공투자 평가 | 사업별 생산·부가가치·임금·수입 유발효과를 예산 1조원당으로 비교 |
| 공급망·수입대체 | 수입 중간재를 국산으로 바꿨을 때의 생산·부가가치·수입 변화, 수입 의존도 순위 |
| 파급경로 추적 | 수요가 0차·1차·2차…단계로 퍼지는 경로와 단계별 주요 산업 |
| 가격 파급 시뮬레이터 | 요금 인상·수입재 가격 상승이 산업 비용, 물가, 영업잉여에 미치는 영향 |
| 가상 제거법 | 한 산업이 사라질 때 총산출·부가가치 손실과 가장 크게 타격받는 산업 |

| 결과 내려받기 | 시뮬레이션 결과(전체 산업)를 CSV로 저장 |
| 계수 검증 | 불러온 자료의 계수 간 항등식을 자동 점검 (잔차 허용값 1e-8) |

## 2. 사용법

1. 페이지 상단의 분류 선택 목록에서 **기본부문 / 소분류 / 중분류 / 대분류**를 고르고 **불러오기** 버튼을 누릅니다. 처음에는 Python 환경을 내려받느라 수십 초 걸릴 수 있습니다.
2. 상태 문구에 "준비 완료 · 계수 검증 통과"가 뜨면 사용할 수 있습니다.
3. **원자료 탐색**: 시트를 고르고, 행 검색창에 산업명이나 코드를 입력해 행을 선택합니다. 선택한 행이 각 열과 어떤 값으로 연결되는지 아래 표에 나타납니다. 열 검색으로 특정 열만 볼 수 있습니다.
4. **국내 생산물 최종수요 증가 시뮬레이션**
   1. 산업을 검색해 선택하고 증가액(백만원)을 입력한 뒤 *시나리오에 추가*를 누릅니다.
   2. 여러 산업을 추가할 수 있으며 증가액은 합산됩니다.
   3. *파급효과 계산*을 누르면 요약 카드, 상위 15개 산업 그래프, 전체 산업 표가 나옵니다.
   4. *전체 CSV 다운로드*로 결과를 저장합니다.
5. **산업 연쇄효과 분석**: 분류를 불러오면 자동으로 표가 채워집니다. 산업 검색, 정렬 기준 선택, 유형 필터를 쓸 수 있습니다.
6. **최종수요 구조(4)**: 전체 경제의 수요 항목별 유발 비중 표와 산업별 표가 자동 생성됩니다. '전력, 가스, 건설' 같은 공기업 관련 산업 버튼으로 바로 찾고, 행을 클릭하면 상세 구성이 나옵니다.
7. **공공투자 평가(5)**: 산업과 예산을 입력하거나 바로 추가 버튼으로 사업을 담고 *경제효과 비교 계산*을 누릅니다.
8. **공급망·수입대체(6)**: 산업(또는 전 산업)과 대체 비율을 정해 계산합니다.
9. **파급경로 추적(7)**: 산업과 수요 증가액을 정해 *경로 분해*를 누릅니다.
10. **가격 파급(8)**: '전기요금 +10%' 같은 버튼을 누르거나, 국내 가격 인상/수입재 가격 상승 중 하나를 골라 산업과 상승률을 입력합니다.
11. **가상 제거법(9)**: 순위 표에서 산업 행을 클릭하면 상세 영향이 나옵니다.
12. **스코어카드(10)**: 산업 A를 고르고, 원하면 비교 산업 B를 골라 *스코어카드 보기*를 누릅니다.
13. 분류를 바꾸려면 목록에서 다른 분류를 고르고 다시 불러오기를 누릅니다. 시나리오는 초기화됩니다.

## 3. 단위와 자료 해석

- **금액**: 투입산출표의 일반 거래액 단위는 **백만원**입니다. (1,000백만원 = 10억원)
- **계수·지수**: 투입계수, 유발계수, 영향력계수, 감응도계수 등은 **단위가 없는 비율**입니다. 유발계수는 최종수요 1원당 유발되는 원 단위 금액으로 읽습니다.
- **가격 기준**: 생산자가격 기준 투입산출표입니다.
- 구성비, 유발계수 등 요약 행은 값의 성격이 다르므로 행 명칭을 먼저 확인하세요.

## 4. 분석 방법

### 4-1. 기본 계수

- 국산투입계수 행렬 **A<sup>d</sup>**: 산업 j가 1원어치 생산하는 데 투입하는 국내 생산물의 비율
- 수입투입계수 행렬 **A<sup>m</sup>**: 같은 조건에서 수입 중간재의 비율
- 부가가치계수 벡터 **v**: 산업 j의 산출 1원당 부가가치
- 생산유발계수 행렬 **L = (I − A<sup>d</sup>)<sup>−1</sup>** (레온티에프 역행렬)
- 수입유발계수 행렬 **M = A<sup>m</sup> · L**
- 부가가치유발계수 행렬 **V = diag(v) · L**

### 4-2. 수요충격 시뮬레이션

국내 생산물에 대한 최종수요 증가 벡터를 **f**라고 하면 다음과 같이 계산합니다.

- 생산유발액 x = L · f
- 수입유발액 m = M · f
- 부가가치유발액 va = V · f
- 생산승수 = (x의 합) / (f의 합)

수입 완제품을 구매하는 수요는 국내 생산을 늘리지 않으므로 제외하고, 국내 생산물에 대한 수요만 입력해야 합니다.

### 4-3. 연쇄효과 분석

생산유발계수 행렬 L의 원소를 l<sub>ij</sub>, 부문 수를 n이라 하면 다음과 같습니다.

- 영향력계수(후방연쇄) = (Σ<sub>i</sub> l<sub>ij</sub> / n) ÷ (모든 열합의 평균 / n)
- 감응도계수(전방연쇄) = (Σ<sub>j</sub> l<sub>ij</sub> / n) ÷ (모든 행합의 평균 / n)

두 계수 모두 전 산업 평균이 1이 되도록 정규화되어 있습니다.

| 유형 | 영향력계수 | 감응도계수 | 해석 |
|---|---|---|---|
| 중추 산업 | 1 이상 | 1 이상 | 다른 산업에 파급도 크고 받는 영향도 큼 |
| 최종수요 지향 | 1 이상 | 1 미만 | 후방연쇄가 강함 |
| 중간수요 지향 | 1 미만 | 1 이상 | 전방연쇄가 강함 |
| 독립 산업 | 1 미만 | 1 미만 | 다른 산업과의 연결이 약함 |

### 4-3-1. 연쇄효과 보조 지표

- 변동계수(후방) = 열 원소들의 표준편차 ÷ 평균. 값이 클수록 파급효과가 소수 산업에 집중됩니다. 행 방향으로 계산하면 전방 변동계수입니다.
- 직접 부가가치율 = 산업 j의 산출 1원당 부가가치(부가가치계수 v<sub>j</sub>)
- 직접 수입의존도 = 수입투입계수의 열합 Σ<sub>i</sub> a<sup>m</sup><sub>ij</sub>

### 4-3-2. 최종수요 항목별 구조

원자료 '최종수요 항목별 생산유발액'(수입·부가가치도 동일) 시트의 값을 그대로 사용합니다. 산업 i의 생산유발액 중 항목 k의 비중 = (항목 k에 의한 유발액) ÷ (총 유발액). 공공수요 비중 = (정부소비 + 정부고정자본형성) 비중이며, 가장 비중이 큰 항목으로 산업의 '주도 수요' 유형을 정합니다.

### 4-3-3. 부가가치 분해와 사업 비교

총투입계수 시트의 피용자보수(9610), 영업잉여(9621), 고정자본소모(9622), 생산세(9630)가 부가가치계수와 일치함을 확인한 뒤, 유발된 생산액 x에 각 구성계수를 곱해 부가가치유발액을 분해합니다. 사업 비교는 예산 1조원(1,000,000백만원)당으로 환산해 규모가 다른 사업도 같은 기준으로 봅니다. 고용 자료는 원자료에 없어 일자리 수 대신 임금(피용자보수) 유발액을 노동소득 효과로 사용합니다.

### 4-3-4. 수입대체 시뮬레이션

산업 k의 수입 중간재 투입 중 비율 r을 같은 산업의 국산품으로 대체합니다.

- A<sup>d</sup><sub>·k</sub> ← A<sup>d</sup><sub>·k</sub> + r · A<sup>m</sup><sub>·k</sub>, A<sup>m</sup><sub>·k</sub> ← (1 − r) · A<sup>m</sup><sub>·k</sub>
- 새 역행렬 L′ = (I − A<sup>d′</sup>)<sup>−1</sup>, 기준 국산 최종수요 f<sub>d</sub>(국산거래표 최종수요계)에 대해 x′ = L′ f<sub>d</sub>
- 기준 생산 x = L f<sub>d</sub>는 원자료의 총산출과 일치함을 확인했습니다.
- 부가가치 = v · x, 수입 = Σ A<sup>m</sup> x. 가격과 품질이 같고 국내 공급여력이 충분하다고 가정하므로, 생산이 크게 늘어나는 산업(예: 광산품)은 현실적 공급 한계를 따로 점검해야 합니다.

### 4-3-5. 파급경로 분해

L = I + A<sup>d</sup> + (A<sup>d</sup>)² + …이므로 총 생산유발액 x = f + A<sup>d</sup>f + (A<sup>d</sup>)²f + …입니다. 0차는 최초 수요, 1차는 그 산업이 직접 투입하는 중간재 산업의 생산, 2차 이후는 그 산업들의 투입으로 이어집니다.

### 4-3-6. 가격 파급 (Leontief 가격 모형)

비용이 모두 가격에 전가된다고 가정합니다.

- 국내 산업 k의 가격이 α 오를 때: Δp<sub>j</sub> = α · L<sub>kj</sub> / L<sub>kk</sub> (k의 가격은 외생적으로 고정)
- 수입재 i의 가격이 δ<sub>i</sub> 오를 때: 1차 비용상승 c<sub>j</sub> = Σ<sub>i</sub> A<sup>m</sup><sub>ij</sub> δ<sub>i</sub>, 가격 상승 Δp = (L)<sup>T</sup> c
- 국내 최종수요 물가 상승 = Σ<sub>j</sub> w<sub>j</sub> Δp<sub>j</sub> (w는 국산 최종수요 비중)
- 가격을 올리지 못할 때 영업잉여 감소율 ≈ 1차 비용상승 ÷ 영업잉여계수(9621)

국내 가격 공식은 고정 가격 조건을 직접 풀어 구한 값과 일치함을 확인했습니다.

### 4-3-7. 가상 제거법

산업 k를 제거한 경제의 역행렬은 L<sub>−k,−k</sub> − L<sub>−k,k</sub> L<sub>k,−k</sub> / L<sub>kk</sub>로 구하고, 기준 국산 최종수요(k 제외)로 새 생산을 계산합니다. 총산출 손실은 x<sub>k</sub> · (Σ<sub>j</sub> L<sub>jk</sub>) / L<sub>kk</sub>와 같음을 직접 재계산으로 확인했습니다. 후방·전방 연쇄를 한꺼번에 반영한 구조적 중요도로 읽습니다.

### 4-3-8. 스코어카드

영향력계수, 감응도계수, 직접 수입의존도, 공공수요 비중, 가상 제거 손실, 물가 파급력(= (L w)<sub>k</sub> / L<sub>kk</sub>)의 전체 산업 내 백분위를 레이더 차트로 보여 줍니다. 백분위는 불러온 분류의 산업들만 기준으로 합니다.

### 4-4. 계수 검증

자료를 불러올 때 다음 항등식의 최대 절대 잔차가 1e-8 미만인지 확인합니다. 통과하지 못하면 해당 파일을 사용하지 않습니다.

- (I − A<sup>d</sup>) · L = I
- A<sup>m</sup> · L = M
- diag(v) · L = V

### 4-5. 한계

- 투입계수가 고정된 선형 모형이며, 가격 변화와 공급 제약(생산능력, 고용 한계)은 고려하지 않습니다.
- 양의 수요 증가만 지원합니다.
- 고용(일자리 수)과 탄소배출 자료가 원자료에 없어 해당 분석은 하지 않습니다.
- 가격 파급은 완전 전가와 수요 불변을 가정한 상한 추정이며, 가상 제거법은 대체 공급처가 없다는 극단적 가정의 지표입니다.
- 수입대체는 가격·품질 동일, 국내 공급여력 충분을 가정한 상한에 가까운 추정입니다.
- 분류가 거칠수록(대분류) 한 부문에 이질적인 산업이 섞여 있어, 같은 충격도 분류에 따라 결과가 달라질 수 있습니다.

## 5-1. 공기업 업무와의 연결 예

| 질문 | 쓰는 페이지 |
|---|---|
| 전력·가스·수도 산업은 공공수요와 민간수요 중 무엇에 의존하는가 | 4. 최종수요 구조 |
| 도로·철도(SOC), 에너지, 의료 사업 중 같은 예산으로 부가가치와 임금 효과가 큰 사업은 | 5. 공공투자 평가 |

각 분류의 부문 수는 자료를 불러온 뒤 상태 문구("준비 완료 · 분류명 · N개 부문")에서 확인할 수 있습니다. 대분류 부문 코드는 `A`, `C01`처럼 영문이 섞여 있고, 다른 분류는 숫자 코드입니다. 합계·분석지표 행·열(9000번대 코드)은 부문에서 제외합니다.

## 8. 배포 방법

1. GitHub 저장소(Public)에 위 파일을 모두 업로드합니다. 압축 파일은 풀어서 올립니다.
2. **Settings → Pages**에서 Source를 *Deploy from a branch*, Branch를 `main`, Folder를 `/ (root)`로 설정합니다.
3. **Actions** 탭에서 배포 완료를 확인한 뒤 주소로 접속합니다.

## 9. 문제 해결

- 추가 분석 영역 맨 위에 **"버전 확인 완료"**가 보이면 `app.js`, `model.py`, `worker.js`가 모두 같은 버전입니다.
- **붉은 경고 문구**가 보이면 해당 파일이 옛 버전입니다. 저장소 맨 위(최상위)에 최신 파일을 올리고 Commit changes를 누른 뒤 1~2분 후 Ctrl+Shift+R로 새로고침하세요.
- 계산 중 오류가 나면 각 페이지의 상태 문구에 원인이 표시됩니다.
